Chapter 1: Neural Networks, One Lego Block at a Time

Learning Objectives

  • Explain what a loss function measures and minimize it by hand for a simple linear model
  • Describe how a linear regression model can be drawn as a neural network with weights and a bias
  • Explain the role of hidden nodes and activation functions in a neural network
  • Build, by hand, a hidden layer with two nodes that matches a straight line exactly
  • Explain the difference between ReLU and sigmoid activations using the same network

Motivation

  • Neural networks have a reputation for being complicated. They are not.
  • The core idea of this chapter: a neural network builds its prediction by adding up simple pieces, like lego blocks.
  • We will start from a model you already know (linear regression), redraw it as the simplest possible neural network, and then add a hidden layer and see exactly what we gain.
  • Everything on this page is interactive. You will be adjusting the same parameters that gradient descent adjusts during training. When we get to training in a later chapter, you will already know exactly what the optimizer is doing.

1. Linear Regression Recap

  • Let's start with the simplest supervised learning setup: one input feature $x$, one target $y$.
  • Our model is a straight line with two parameters, the weight (slope) $w$ and the bias (intercept) $b$:
$$\hat{y}_i = w x_i + b$$
  • How do we measure how good a particular line is? With a loss function. Here we use mean squared error (MSE):
$$\mathcal{L}(w, b) = \frac{1}{n}\sum_{i=1}^{n} (\hat{y}_i - y_i)^2$$
  • Smaller loss → better fit. The pair $(w^*, b^*)$ with the smallest possible loss is called the least squares solution, and for linear regression it has a closed-form formula.
  • Try it below: drag the two sliders and try to minimize the loss by hand. Then press the button to jump to the least squares solution.

2. Linear Regression as a Neural Network

  • Here is the same model, drawn differently. This diagram is our line:
  • How to read it:
    1. The input node carries the feature $x$; the second input node carries the constant $1$.
    2. Each edge multiplies the value passing through it by its own weight: the $x$ edge carries $w$, the constant edge carries $b$.
    3. The output node sums its incoming values: $\hat{y} = wx + b \cdot 1$.
  • This unit (a weighted sum of inputs, followed by an output) is called a neuron. Linear regression is a neural network with a single neuron and no hidden layer.
  • Note that training changes nothing about the picture. Training only changes the numbers on the edges, which is exactly what you were doing with the sliders above.
  • One neuron can only ever draw a straight line. To draw anything else, we need to put neurons between the input and the output: a hidden layer.

3. Adding a Hidden Layer: Lego Blocks

  • Let's add the smallest possible hidden layer: two hidden nodes, giving a 1 → 2 → 1 network.
  • Each hidden node computes a weighted sum, exactly like before, but then passes the result through an activation function $\phi$ before sending it on:
$$h_i = \phi(w_i x + b_i), \qquad \hat{y} = v_1 h_1 + v_2 h_2 + c$$
  • Two common choices of $\phi$:
    • $\text{ReLU}(z) = \max(0, z)$: outputs zero until $z$ turns positive, then a ramp;
    • $\phi(z) = \frac{1}{1 + e^{-z}}$: the sigmoid, a smooth step from 0 to 1.
  • The key intuition: each hidden node contributes one simple shape (a lego block) and the output layer adds the blocks together.
  • Each block below has three parameters: its location (the point where a ReLU ramp bends, or the center of a sigmoid step; this sets $b_i = -w_i \cdot \text{location}$), its slope $w_i$, and its height $v_i$. These are exactly the parameters gradient descent tunes during training. The output bias $c$ is set automatically.
  • The gray dots below are the same data from section 1, and the loss is the same MSE against those points, so the numbers here are directly comparable to the least squares loss you found there.

  • Did you notice the parameter values? To look like a straight line, sigmoid blocks need extreme settings: a small $w$ and a very large $v$ (press fit and watch $v$ climb almost to the edge of its slider range). That is because a sum of sigmoid curves is never exactly straight; it can only stretch its nearly linear middle across the plot.
  • ReLU blocks needed nothing extreme: they are made of straight pieces, so a line is matched exactly, via $a x = a\,\text{ReLU}(x) - a\,\text{ReLU}(-x)$.
  • Takeaway: the choice of activation decides what kind of pieces the network builds with, and different pieces are good at different shapes.

(Optional) The Same Network in Code

  • The entire two-block network is a few lines of numpy:
h1 = np.maximum(0, w1 * x + b1)      # hidden node 1  (b = -w * location)
h2 = np.maximum(0, w2 * x + b2)      # hidden node 2
y_hat = v1 * h1 + v2 * h2 + c        # output: add the blocks
loss  = np.mean((y_hat - y) ** 2)    # MSE, the loss you watched above
  • And the same model in PyTorch. Note how each line of code maps onto a piece of the diagram above:
model = nn.Sequential(
    nn.Linear(1, 2),   # x -> two hidden nodes   (the w's and b's)
    nn.ReLU(),         # the activation          (swap in nn.Sigmoid() to compare)
    nn.Linear(2, 1),   # add the blocks          (the v's and c)
)

Chapter Highlights

  1. Linear regression is a neural network with a single neuron and no hidden layer.
  2. Training means adjusting the weights and biases to minimize a loss function (here, MSE).
  3. Each hidden node contributes one simple shape (a lego block), and the output node adds the blocks together.
  4. Two ReLU blocks can reproduce a straight line exactly; sigmoid blocks can only approximate one.
  5. The choice of activation function decides what kind of pieces the network builds with.
